# Заметки по лабораторной 02: Git и GitHub

## Три локальных состояния Git

- **Рабочая папка** — обычные файлы на диске, которые я открываю и правлю в редакторе. Git видит, что они изменились, но пока ничего не сохраняет.
- **Индекс (staging area)** — «корзина» для следующего коммита. Командой `git add` я кладу в неё именно те изменения, которые хочу сохранить вместе.
- **Коммит** — зафиксированный снимок проекта с автором, временем и сообщением. Коммит неизменяем и навсегда остаётся в истории.

Путь изменения: рабочая папка → (`git add`) → индекс → (`git commit`) → коммит.
